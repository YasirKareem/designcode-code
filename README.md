# Design&Code — كود الحلقات

الكود الكامل لكل حلقة من سلسلة Design&Code على إنستغرام.
كل مجلد مشروع جاهز: افتح `index.html` في المتصفح وجرّب مباشرة، بدون تثبيت أي شيء.

تعلّم CSS وJavaScript من خلال مقاطع تعليمية ومشاريع تفاعلية قابلة للتجربة.
تابع **[@designcode_17](https://www.instagram.com/designcode_17/)** 🎬

يُضاف كود كل حلقة يوم نشر الريل الخاص بها.

## طريقة الاستخدام

- **للتجربة:** افتح المجلد واضغط مرتين على `index.html`.
- **للتعديل:** افتح المجلد في VS Code، وغيّر الألوان والأرقام وشاهد النتيجة.
- **للتحميل:** زر **Code** الأخضر ← **Download ZIP**.

عندك سؤال أو تريد درسًا معينًا؟ اكتبه في تعليق على الريل.
