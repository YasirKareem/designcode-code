# حروف تتحول إلى جسيمات تفاعلية

هكذا تبدأ المؤثرات التفاعلية باستخدام `Canvas`.

## التشغيل

1. حمّل المجلد (أو المستودع كاملًا).
2. افتح `index.html` في المتصفح بنقرة مزدوجة. لا يحتاج أي تثبيت.

## الملفات

- `index.html`
- `main.js`
- `style.css`

---

تعلّم CSS وJavaScript من خلال مقاطع تعليمية ومشاريع تفاعلية قابلة للتجربة.
تابع **[@designcode_17](https://www.instagram.com/designcode_17/)** 🎬
